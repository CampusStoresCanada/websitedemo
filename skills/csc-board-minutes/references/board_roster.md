## Building the Present/Absent list

The Notion transcript does **not** label who is speaking — turns are just
dialogue, occasionally with a name mentioned in context ("Sean, go ahead",
"Kevin, your hand is up"). To build Present/Absent:

1. Look for a roll-call or "who's missing" moment near the start of the
   transcript (there usually is one, even if informal/chatty).
2. Cross-reference every name mentioned as speaking or being addressed
   against the roster above.
3. Anyone on the roster who never speaks and is never addressed is
   presumptively Absent — but treat this as a draft, not a certainty, and
   flag it to the user rather than silently asserting it.
4. **Sean Bell and Shawn Davies are easy for the transcription to confuse**
   (similar first names, "Sean"/"Shawn" spelled inconsistently by the
   transcript). Do not assume attendance for either of them from name
   spelling alone — check what they actually say/are asked and, if it's
   ambiguous, ask the user to confirm before finalizing.

## Known recurring transcription errors

The auto-transcription consistently mangles certain proper nouns. Always
scan the raw transcript for these and correct them; also watch for new
patterns and ask the user whether to add them here.

| Correct | Seen as |
|---|---|
| CANCOLL | CanCall, Cancall, Can Call |
| CSC (Campus Stores Canada) | CSE |
| Sean Bell | Shawn Bell, Shaun Bell (name is fine, just double-check this is really him speaking) |
| Shawn Davies | Sean Davies, Shaun Davies (this transcription consistently writes his name as "Sean Davies" — always normalize to "Shawn Davies") |

If you spot a new one during a run — a name, acronym, or org that's clearly
wrong in a consistent way — fix it in the draft, tell the user what you
corrected, and offer to add it to this table for next time.
